How to embed

Drop the bundle onto any page with one <script type="module"> tag, then use the custom elements directly in HTML. The bundle registers the elements as a side effect, so they upgrade as soon as the module finishes evaluating. 

<script type="module" src="http://localhost:3000/embed/embed.es.js"></script>

<debrain-counter></debrain-counter>
<debrain-counter count="10" label="Visitors"></debrain-counter>

If the site's CMS doesn't allow type="module", use the IIFE bundle with a classic script tag instead. It registers the same elements and exposes the exports as window.DebrainEmbeds. Load only one of the two bundles on a page. 

<script src="http://localhost:3000/embed/embed.iife.js" defer></script>

<debrain-counter></debrain-counter>
CSS is bundled inline. You don't need a separate <link rel="stylesheet"> — styles are injected into <head> by the bundle on first use, exactly once per component.

<debrain-counter> — API

A minimal counter button demonstrating the structure: Lit element rendered in light DOM (no shadow DOM), SCSS-scoped styles via class prefixes, and a custom event.

Attributes

Name Type Default Description
count number 0 Initial counter value. Reflected back to the DOM attribute on change.
label string "Counter" Text shown next to the value.

Events

Name Detail Description
debrain-counter:change { count: number } Fired every time the counter is incremented. Bubbles, composed.

Listening to the event

document.addEventListener('debrain-counter:change', (e) => {
  console.log('New value:', e.detail.count);
});

Only the component, no surrounding chrome — use this to test full-width or full-height components.

/embed/embed.es.js bundle

ES module bundle. Use with <script type="module"> or import(). Registers the custom elements as a side effect.

/embed/embed.iife.js bundle

Classic-script (IIFE) bundle for CMSs that don't allow ES modules. Use with a plain <script>; exports land on window.DebrainEmbeds. Test it at /example/iife/ (production build only).

Conventions & security

Light DOM

Components render in light DOM — no shadow root — so consumer pages can style them if needed. Classes are BEM-prefixed (.debrain-counter__btn) to avoid collisions.

CORS & helmet

/embed/* is served with Access-Control-Allow-Origin: * and Cross-Origin-Resource-Policy: cross-origin. Consumer sites define their own CSP.
